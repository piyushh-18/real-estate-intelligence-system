# Real Estate Intelligence System

**Description:**  
An end-to-end machine learning project for property price prediction and investment decision support using historical data. MySQL is used as the data source and to store prediction results.

**Features:**  
- Predict fair property prices using ML  
- Feature importance analysis for price transparency  
- Decision support for buyers and investors  
- MySQL database integration for real-world data handling

**Tech Stack:**  
- Python, Pandas, Scikit-learn  
- MySQL, SQLAlchemy  
- VS Code, Git & GitHub  

**Folder Structure:**  
- `data/` : Raw & processed datasets  
- `notebooks/` : Jupyter notebooks for exploration  
- `src/` : Python scripts for ML pipeline  
- `models/` : Trained model files  
- `reports/` : Analysis reports
